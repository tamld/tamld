## 🧭 Principles

- **Mechanism over prompting** — Don't instruct AI to be careful; build a guardrail that makes mistakes impossible
- **Evidence over plausibility** — If you didn't verify it, tag it `[HYPO]`
- **Stability over complexity** — Fewer moving parts, fewer failures
- **Document along the way** — Systems outlive their builders
